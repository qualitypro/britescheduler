# Cycle 90AL — Compact module navigation

Restored CRM navigation as a compact vertical icon tab rail (nine unique icons), without the horizontal tab scrollbar. The active CRM tab remains a normal link with `aria-current=page`; GET and POST routes remain unchanged. Messaging panes and thread rows are also compacted, with a single-column responsive layout on narrow screens. The application sidebar accordion and Subscriptions heading are preserved.
